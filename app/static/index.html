실제 악용 (KEV)
미국 CISA가 "실제 공격에 쓰였다"고 확인한 취약점 목록. 점수와 상관없이 가장 먼저 처리합니다.
CVSS 점수
0~10점 심각도. 9.0 이상이 Critical. 점수가 높아도 실제 공격이 없을 수 있고, 반대도 있습니다.
PoC 공개
공격 방법을 보여 주는 코드가 공개됨. 곧 실제 공격으로 이어지기 쉽습니다.
인증 없이 원격
로그인 없이 네트워크 너머에서 공격할 수 있음. 외부에 열린 서비스라면 특히 급합니다.
경계 장비
VPN·방화벽·공유기처럼 인터넷과 내부망 사이에 있는 장비. 공개 직후 대량 스캔이 시작됩니다.
확인함
처리했거나 해당 없음을 확인한 항목. 오늘의 판정에서 빠집니다(이 브라우저에만 저장).

        실제 악용

        미국 CISA가 실제 공격에 쓰였다고 확인한 취약점입니다.

        • 불러오는 중…

        자료

        취약점을 처음 확인할 수 있는 곳과 악용 여부를 알려 주는 곳입니다.

        먼저 알아둘 변화. 2026년 4월 15일부터 NIST NVD는 모든 CVE를 분석하지 않습니다. KEV 등재 CVE, 연방정부 사용 소프트웨어, 핵심 소프트웨어만 우선 보강하고, 나머지는 CVE를 등록한 CNA(주로 벤더)의 점수를 그대로 씁니다. 그래서 이 페이지는 NVD가 아니라 CVE 원본 레코드의 CNA 점수와 CISA 보강 데이터(Vulnrichment)를 읽습니다.

        대응 루틴

        매일·매주 무엇을 보면 되는지 정리했습니다.

        보안 담당자용

        1. SLA를 점수가 아니라 악용 여부로

          KEV 등재는 CVSS와 상관없이 최우선. 인사이트 탭의 "CVSS만 보면 놓치는 KEV" 비율이 그 근거입니다. 예: KEV+외부 노출 72시간, KEV 내부 7일, 그 외 Critical은 EPSS·SSVC로 차등.

        2. 경계 장비는 따로 관리

          VPN·방화벽·게이트웨이 취약점은 공개 직후 대량 스캔이 시작됩니다. 패치와 함께 벤더가 낸 침해지표(IoC) 점검, 관리 인터페이스 외부 노출 차단까지 한 묶음으로.

        3. 자산 인벤토리와 자동 대조

          CPE·SBOM 기준 자산 목록을 KEV JSON과 매일 대조합니다. 이 페이지의 실제 악용 목록이 같은 역할을 합니다.

        4. 레거시 백로그를 버리지 않기

          KEV 등재의 상당수는 공개된 지 1년이 넘은 취약점입니다. 오래된 미패치 자산이 계속 공격 대상이 됩니다.

        5. 정기 패치일에 대비

          MS 패치 화요일(한국 수요일 새벽), Oracle CPU(1·4·7·10월), Chrome 주간 릴리스, Android·삼성 월간 게시판. 신규 Critical 일별 그래프의 급증일이 대부분 이런 날입니다.

        개인용

        1. 자동 업데이트부터 켜기

          Windows, macOS·iOS, Android·갤럭시, Chrome·Edge. 브라우저는 업데이트 후 재시작해야 적용돼요.

        2. 매일 아침 1분

          "오늘" 화면의 판정을 봅니다. 0건이면 끝, 있으면 벤더 공지에서 버전을 맞춥니다.

        3. 집 안의 잊힌 장비

          공유기, NAS(Synology·QNAP), IP카메라, VPN 앱. 상단 검색에 모델명을 넣어 확인하세요.

        4. 국산 소프트웨어는 KISA로

          보안 플러그인, 한컴오피스, 국산 백신은 보호나라 보안공지가 가장 빠르고 정확합니다.

        KEV 신규 항목만 뽑기

        # 최근 7일 추가된 KEV
curl -s https://raw.githubusercontent.com/cisagov/kev-data/main/known_exploited_vulnerabilities.json \
| jq -r --arg d "$(date -d '-7 day' +%F)" \
  '.vulnerabilities[] | select(.dateAdded >= $d)
   | "\(.dateAdded) \(.cveID) \(.vendorProject) \(.product)"'

        EPSS 점수 조회 · OSV 스캔

        # EPSS (30일 내 악용 확률)
curl -s "https://api.first.org/data/v1/epss?cve=CVE-2026-48356"
# 프로젝트 의존성 검사
osv-scanner scan -r .

        서버에서 정해진 일정(기본: 매일 오전 8시 40분 KST)에 자동 갱신됩니다. 한국어 설명은 LibreTranslate 기계 번역이라 어색할 수 있으니 원문(영문)과 벤더 공지를 함께 확인하세요. 데이터: CISA KEV(GitHub 공식 미러), CVE List V5(CVEProject/cvelistV5), CISA Vulnrichment(SSVC). CVSS는 CNA 점수를 우선하고, 없으면 CISA ADP 점수를 씁니다. "경계 장비"는 벤더·제품명 기반 추정입니다. 조치 판단은 벤더 공지로 최종 확인하세요.
